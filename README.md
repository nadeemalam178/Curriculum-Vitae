# HTML Curriculum Vitae Documents

A lightweight collection of responsive, print-ready HTML/CSS Curriculum Vitae templates engineered for clean ATS readability and physical A4 printing.

## 📄 Overview
- **Print Optimization:** Embedded `@media print` rules removing headers, interactive controls, and setting exact A4 margins.
- **Semantic Structure:** Clean HTML5 markup optimized for automated ATS parsers and screen readers.
- **Styling:** Modular CSS layout supporting dark/light previews.

## 🚀 Usage
Open any `.html` file directly in a modern web browser, or preview via live server. Use `Ctrl + P` / `Cmd + P` to export cleanly to PDF.
